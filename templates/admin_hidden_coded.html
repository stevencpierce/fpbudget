A charge a project coded — to a line, a section or a split — can never also be Not project for that project. When a Not project mark is found on one anyway (a dismissal the company-ledger migration wrote for the project that kept the row, or a leftover exclusion flag), the charge is off the Assigned list and its line shows $0. Fix removes the mark: the charge returns to Assigned and counts on its line again. Every Fix is logged and can be undone. The project's Actuals page applies the same repair on its own when it loads, so this list is normally empty.
